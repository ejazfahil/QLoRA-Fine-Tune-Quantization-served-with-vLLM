# Dataset schema & splits

## Source
[`databricks/databricks-dolly-15k`](https://huggingface.co/datasets/databricks/databricks-dolly-15k)
— ~15k human-written instruction/response pairs across closed-QA, open-QA,
summarization, brainstorming, etc. Chosen because it is open (CC-BY-SA), mixes
closed-book and context-grounded tasks (good for ROUGE-L / exact-match), and is
comparable to published instruction-tuning numbers.

Field mapping (source → our schema), configured in `configs/*.yaml`:

| our field     | dolly field   |
| ------------- | ------------- |
| `instruction` | `instruction` |
| `input`       | `context`     |
| `output`      | `response`    |

## On-disk format
One JSON object per line (`data/processed/{train,val,test}.jsonl`):

```json
{
  "instruction": "Summarize the key risks.",
  "input": "Optional supporting context. Empty string if none.",
  "output": "The reference answer.",
  "text": "Below is an instruction... ### Response:\nThe reference answer.\n"
}
```

- `text` is the **rendered Alpaca prompt + answer** — the exact training target.
  The same template (`common/prompt.py`) is used at eval time so the model is
  scored in the format it was trained on.
- A 5-row `data/sample.jsonl` is committed so the schema is self-documenting;
  the full splits are git-ignored and regenerated by `make data`.

## Splits
Deterministic, seeded by the global `seed` (default 42). The dataset is shuffled
once, then sliced:

```
test  = floor(N * test_fraction)
val   = floor(N * val_fraction)
train = N - val - test
```

Default fractions (production configs): `val=0.05`, `test=0.05`.
`data/processed/split_meta.json` records the exact counts, seed, and fractions
for every run.

## Reproduce
```bash
make data                                          # uses configs/smoke.yaml
uv run python -m data.prepare_data --config configs/mistral7b_qlora.yaml
```
